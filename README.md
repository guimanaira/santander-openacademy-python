# ♨️ Santander Open Academy- Python Fundamentos 

Bem-vindo(a) a este repositório de estudos em **Python**, desenvolvido a partir do curso oferecido pelo **Santander Open Academy**.
Aqui estão organizados meus estudos sobre os **fundamentos da programação em Python**, incluindo configuração do ambiente, lógica de programação e 
desenvolvimento de programas básicos, sempre com foco em **boas práticas, legibilidade e organização do código**.
Este repositório reflete meu compromisso com o **aprendizado contínuo** e a construção de uma **base sólida em programação**, 
utilizando exemplos práticos e explicações claras — habilidades essenciais para quem está iniciando na área de tecnologia e dados.


# 📚 Conteúdos Principais

- Introdução ao Python
- Fundamentos do Python
- Estruturas de controle
- Estruturas de dados
- Funções
- Tratamento de erros e exceções
- Entradas/saídas
- Importação e criação de módulos
