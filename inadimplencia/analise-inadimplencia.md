# 🔍 Análise de Clientes Inadimplentes

## 🚀 Desafio

O desafio consiste em **desenvolver uma análise simples de clientes inadimplentes**, utilizando Python para identificar atrasos de pagamento e **gerar automaticamente uma lista organizada para cobrança**.
A aplicação simula um cenário real do setor financeiro, onde analistas de dados e equipes de crédito precisam **avaliar inadimplência, classificar risco e fornecer informações claras para tomada de decisão**, garantindo agilidade e organização no processo de cobrança.



## 🎯 Objetivo Geral

- Analisar uma base de clientes a partir de um arquivo CSV.
- Identificar clientes com status de inadimplência.
- Classificar o risco de crédito com base em score.
- Gerar automaticamente uma lista de clientes para cobrança.
- Organizar e estruturar dados financeiros de forma clara e acessível.
- Demonstrar lógica de classificação e análise de risco.



## 🤖 Ferramentas e Conceitos Aplicados

- **Python**
- Leitura e escrita de arquivos CSV
- Manipulação de dados com dicionários e listas
- Funções
- Estruturas condicionais
- Organização de código em módulos
- Classificação baseada em regras de negócio
- Geração de arquivos para uso operacional



## 🧠 Processo de Criação

O projeto foi estruturado seguindo boas práticas de organização e clareza, simulando um fluxo comum utilizado em análises financeiras e de risco.

- Leitura e normalização dos dados a partir de arquivo CSV.
- Conversão dos registros em estruturas de dados manipuláveis.
- Filtragem dos clientes inadimplentes com base em regras claras.
- Classificação de risco de crédito utilizando score.
- Geração de um arquivo final para apoio ao time de cobrança.
- Separação entre lógica de análise e execução do sistema.

Essa abordagem reflete o pensamento analítico necessário para atuar com **dados financeiros e análise de risco**.
