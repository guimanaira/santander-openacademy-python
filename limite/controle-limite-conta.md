# 🏦 Sistema de Controle de Limite de Conta

## 🚀 Desafio

O desafio consiste em **aplicar conceitos intermediários de Python para desenvolver um sistema de controle de conta bancária**, simulando funcionalidades básicas utilizadas por instituições financeiras no dia a dia.

A aplicação permite **depósitos, saques, controle de limite**, verificação de **saldo disponível** e **bloqueio automático por uso excessivo de saques**, garantindo segurança, organização e tratamento adequado de erros.

O projeto simula cenários reais enfrentados por sistemas bancários e equipes de tecnologia financeira (*fintechs e bancos tradicionais*).


## 🎯 Objetivo Geral

- Desenvolver um sistema simples de conta bancária via terminal
- Controlar saldo do cliente
- Definir limite máximo para saque
- Restringir quantidade diária de saques
- Exibir extrato bancário
- Tratar erros de operação de forma controlada



## 🤖 Ferramentas e Conceitos Aplicados

- **Python**
- Terminal / Console
- Editor de código (VS Code)
- Programação Orientada a Objetos (Classes)
- Funções
- Estruturas condicionais (`if / elif / else`)
- Exceções personalizadas (`raise`, `try / except`)
- Organização modular do código



## 🧠 Processo de Criação

O projeto foi estruturado em módulos para garantir **clareza, organização e boas práticas**, simulando um ambiente profissional de desenvolvimento.

- Criação da classe `Conta` para encapsular as regras bancárias
- Implementação de métodos específicos para depósito, saque e extrato
- Definição de exceções personalizadas para cada tipo de erro
- Separação da lógica de negócio, tratamento de erros e fluxo principal
- Simulação de uso real de uma conta bancária via menu interativo
