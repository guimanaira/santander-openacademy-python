# 📝 Gerador de Relatório Bancário Diário

## 🚀 Desafio

O desafio consiste em **aplicar conceitos de Python para desenvolver um sistema de geração de relatório bancário diário**, a partir da leitura de um arquivo CSV contendo transações financeiras.

A aplicação simula um cenário real do setor bancário e financeiro, onde é necessário **analisar grandes volumes de dados transacionais**, gerar **insights relevantes** e apresentar informações consolidadas para apoio à tomada de decisão.



## 🎯 Objetivo Geral

- Ler dados de transações bancárias a partir de um arquivo CSV
- Calcular o **total de transações realizadas**
- Calcular o **valor total movimentado**
- Identificar a **maior** e a **menor operação financeira**
- Retornar os dados consolidados de forma estruturada
- Simular a geração de um **relatório bancário diário**



## 🤖 Ferramentas e Conceitos Aplicados

- **Python**
- Leitura de arquivos CSV (`csv.DictReader`)
- Escrita e leitura de arquivos
- Funções
- Estruturas de dados (listas e dicionários)
- Estruturas condicionais
- Tratamento de exceções (`try / except`)
- f-strings
- Organização modular do código



## 🧠 Processo de Criação

O projeto foi desenvolvido com foco em **clareza, simplicidade e boas práticas**, simulando atividades comuns realizadas por **analistas de dados e equipes de tecnologia bancária**.

- Leitura estruturada do arquivo CSV contendo transações bancárias
- Conversão e validação de dados numéricos (`TransactionAmount`)
- Tratamento de linhas inválidas para evitar falhas na execução
- Cálculo de métricas financeiras relevantes
- Retorno das informações consolidadas por meio de dicionário
- Separação da lógica de processamento e execução principal



## 📁 Estrutura do Projeto
