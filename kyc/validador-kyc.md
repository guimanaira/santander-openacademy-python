# 🔐 Validador de Dados de Clientes (KYC)

### 🚀 Desafio

O desafio consiste em **aplicar conceitos fundamentais de Python para criar um sistema simples de validação de dados cadastrais de clientes**, simulando um processo básico de **KYC (Know Your Customer)** utilizado no setor bancário e financeiro.

A aplicação deve validar informações essenciais como **idade mínima**, **CPF válido** e **renda mínima exigida**, garantindo a **qualidade dos dados**, prevenindo inconsistências e tratando erros de forma adequada. O projeto simula cenários reais enfrentados por analistas de dados e equipes de compliance no dia a dia.

---

### 🎯 Objetivo Geral

- Desenvolver um validador simples de dados cadastrais de clientes para processos de KYC.
- Validar idade mínima do cliente
- Verificar formato e validade do CPF
- Conferir se a renda atende ao valor mínimo exigido
- Tratar erros de entrada de dados de forma controlada

---

### 🤖 Ferramentas e Conceitos Aplicados

- **Python**
- Terminal / Console
- Editor de código (VS Code)
- Funções
- Estruturas condicionais (`if / else`)
- Exceções personalizadas (`raise`, `try / except`)
- Entrada e validação de dados do usuário

---

### 🧠 Processo de Criação

O projeto foi estruturado em módulos para garantir **organização, reutilização de código e clareza**, simulando boas práticas utilizadas em ambientes profissionais.

- Criação de funções específicas para cada validação (idade, CPF e renda)
- Implementação de exceções personalizadas para erros de cadastro
- Separação da lógica de validação, erros e execução principal
- Simulação de fluxo real de cadastro de cliente
